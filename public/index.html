▪ A circuit-breaker for risky agent actions

Agents move fast. Humans hold the keys to the irreversible.

Interlock sits at the execution boundary of your AI agents. When an action is high-stakes — moving money, changing a payout account, deleting data — it pauses, asks a human to approve the exact action with a passkey, and only then lets the agent run it, exactly once.

Guarantees
Single-use

No double-spend

Each approval mints one proof that is consumed exactly once. Replays are refused.

Bound

What's approved is what runs

The proof binds to the exact parameters. Approve $10, try to run $10,000 — blocked.

Fail-closed

Never a silent yes

If anything is off — expired, tampered, or the authority is unreachable — it refuses.

Durable

Survives restarts

Approvals and one-time consumption persist to disk, so state is never lost.
